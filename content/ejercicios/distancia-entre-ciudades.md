# Distancia entre ciudades

##  Enunciado

Queremos realizar diversos cálculos con las distancias entre distintas ciudades. Para ello diseña los siguientes apartados: 

  1. Un subalgoritmo que devuelva una lista de ciudades introducidas por el usuario. 
  2. Un subalgoritmo que pida al usuario las distancias entre las distintas ciudades y las devuelva (si entre dos ciudades no hay conexión la distancia será -1). 
  3. Un subalgoritmo que con los datos anteriores devuelva en nombre de las 2 ciudades con menor distancia. 
  4. Un subalgoritmo que con los datos obtenidos de los apartados 1 y 2, y una distancia dada, nos devuelva las parejas de ciudades con un distancia menor que la dada. 
  5. Un algoritmo que, utilizando los subalgoritmos anteriores, lea los nombres de las ciudades, las distancias entre ellas y muestre un menú donde podamos elegir si queremos ver la pareja de ciudades con menor distancia y las parejas de ciudades con una distancia menor que una dada.
