    Modificar el programa de Suma primeros cinco números naturales#

    Enunciado#

    MODIFICA EL PROGRAMA SUMAINT.C.

    Se trata del programa que suma los cinco primeros enteros que se presentó en el Ejercicio sumaint.c. En primer lugar se deberá editar este programa y salvarlo con el nombre sumaFor.c. Se te pide que modifiques la copia (sumaFor.c) para que el programa realice lo mismo(sumar los cinco primeros enteros), pero empleando un bucle for en lugar de un bucle while.

    Soluciones#

    Programa en C por Angel#

    Solución comentada del Ejercicio:

    
/* fichero sumaFor.c */
#include <stdio.h>
void main(void) {
  int i, suma=0;
  for(i=0; i<=5; i++)
       suma+=i;
  printf("La suma de los cinco primeros numeros es: %d\n", suma);
}

    Comentario#

    En este fichero se ha utilizado la equivalencia directa entre los bucles for y while. Por lo demás, este programa no tiene nada de particular.
